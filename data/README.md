# Datos locales

Este directorio se entrega vacío. El pipeline crea aquí sus entradas y resultados tabulares durante una ejecución operativa, pero `.gitignore` impide versionarlos.

- `raw/`: capturas e identificadores conocidos.
- `processed/`: variables normalizadas y predicciones.
- `private/`: perfiles y preferencias con acceso restringido.

Usa únicamente datos propios o con autorización compatible con el proyecto.
