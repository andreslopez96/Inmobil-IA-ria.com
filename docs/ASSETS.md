# Recursos de informes

La edición pública usa una plantilla LaTeX compuesta únicamente por texto, formas y colores. No incluye logotipos, fotografías de anuncios ni recursos gráficos del proyecto privado.

Las portadas obtenidas durante una ejecución operativa se guardan en `artifacts/reports/`, una ruta ignorada por Git. Antes de compartir un informe, deben revisarse tanto los datos personales como los derechos de uso de sus imágenes.
